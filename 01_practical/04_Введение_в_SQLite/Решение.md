## Вопросы

В определении id INTEGER без PRIMARY KEY нет связи с rowid и не гарантирована автоматическая выдача id. INTEGER PRIMARY KEY использует rowid; AUTOINCREMENT нужен только для запрета повторного использования ранее выданных значений.

SELECT sqlite\_version() возвращает строку версии именно используемой библиотеки SQLite; фактическое значение записано в Результаты.json.
