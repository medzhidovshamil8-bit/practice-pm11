## Вопросы

В ошибочном CASE отсутствует END перед FROM. COALESCE(NULL,NULL,5) возвращает 5\.

UPDATE с CASE возможен. Например, UPDATE product SET price=CASE WHEN price\<0 THEN 0 ELSE price END; но в этой таблице отрицательная цена не может быть сохранена из\-за CHECK, поэтому исправлять нечего. Для очистки старых данных без CHECK сначала пересоздают таблицу или работают в staging-таблице.
