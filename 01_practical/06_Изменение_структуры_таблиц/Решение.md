## Особенности SQLite

Задание «добавить created TEXT DEFAULT (date('now'))» невозможно выполнить простым ALTER TABLE ADD COLUMN: SQLite запрещает непостоянное выражение DEFAULT при таком добавлении. В безопасном сценарии использован константный DEFAULT; для динамической даты нужно пересоздать таблицу с DEFAULT (date('now')).

ALTER TABLE product ALTER COLUMN price TYPE REAL в SQLite не поддерживается. Нужно пересоздать таблицу и перенести данные. ADD COLUMN new\_col TEXT не меняет число строк: SELECT COUNT(\*) вернет 5; у существующих строк new\_col будет NULL.
