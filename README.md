## Повторный запуск

Требуется Python 3.10+ и SQLite 3.37+ (STRICT-таблицы).
Из корня проекта:

```sh
python 02_individual/scripts/rebuild.py --force
```

Команда пересоздаёт только учебную базу проекта. Без `--force` существующая БД
защищена от перезаписи. Скрипт создаёт таблицы, импортирует CSV, проверяет
некорректные строки и ссылочную целостность, создаёт индексы и выполняет запросы.
Результаты сохраняются в `02_individual/results/`.

В DB Browser откройте `02_individual/travel_agency.db`, выполните
`PRAGMA foreign_keys=ON;` и запросы из `sql/03_queries.sql`.
Суммы хранятся целыми копейками, даты — YYYY-MM-DD, пустой email импортируется как NULL.

Контрольные результаты: 9 активных бронирований, 16 туристов, договоры на 980000 руб.,
поступления 545000 руб., долг 435000 руб. `integrity_check=ok`, нарушений FK нет.

## Границы модели

Модель учитывает заказчика и число туристов, без персональных данных каждого путешественника,
виз, билетов и возвратов. Межтабличные ограничения вместимости и сумм платежей
требуют прикладной транзакционной логики при промышленном внедрении.
